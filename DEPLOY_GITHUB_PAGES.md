# Road 2 Safety International — Free GitHub Pages Deployment

This folder is ready to publish as a static GitHub Pages site.

## Public structure
- `/` — Road 2 Safety International holding website
- `/app/` — Road 2 Safety Navigator installable PWA prototype
- `/documents/` — selected public institutional documents

## Before making it public
1. Confirm the wording `Road 2 Safety International — In formation as a UK Community Interest Company` remains correct.
2. Keep `Road2SafetyCIC@gmail.com` protected with MFA.
3. Do not add medical records, addiction histories, child case data, precise location, or confidential referral data to this static site.
4. Verify any Sierra Leone emergency, treatment or referral contacts before publishing them.
5. Do not describe proposed partners as confirmed partners without written agreement.

## GitHub Pages route
1. Create a new GitHub repository (for example `road-2-safety`).
2. Upload the *contents* of this folder to the repository root.
3. In repository Settings → Pages, choose `Deploy from a branch`.
4. Select the `main` branch and `/ (root)` folder, then Save.
5. GitHub will provide an HTTPS `github.io` address.
6. Open `/app/` on the deployed site and test Add to Home Screen / install behaviour.

No paid hosting or custom domain is required for this staging route.
